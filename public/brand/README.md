# Brand assets

Drop the school's official emblem here as **`school-logo.png`** (square, transparent
background, ≥ 256 px). It appears in the sidebar, the mobile drawer, the sign-in
page and the report-card letterhead. Until the file exists, the app falls back to a
typographic monogram (`SM`) — no invented logo.

Optionally add a sign-in hero photograph to `public/` (e.g. `school-login.webp`) and
point `NEXT_PUBLIC_SCHOOL_LOGIN_IMAGE` at it. With no photo set, the sign-in page
shows a plain branded panel instead.
